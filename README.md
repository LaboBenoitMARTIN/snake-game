# 🐍 Snake

Le jeu Snake classique, en JavaScript vanilla — sans framework, sans dépendance. Dirigez le serpent, mangez les pommes, évitez les murs et votre propre queue.

## Comment jouer

Ouvrez `index.html` dans un navigateur, ou activez GitHub Pages (voir plus bas) pour y jouer directement en ligne.

- **Flèches directionnelles** ou **Z Q S D** pour diriger le serpent
- Le serpent accélère légèrement à chaque pomme mangée
- Le meilleur score est sauvegardé dans le navigateur (`localStorage`)

## Technologies

HTML5 Canvas, CSS3, JavaScript vanilla (ES6+) — aucune dépendance, aucun build.

## Jouer en ligne

Pour obtenir un lien à partager : **Settings → Pages → Deploy from branch → `main` / `root`**. Le jeu sera disponible à l'adresse `https://labobenoitmartin.github.io/snake-game/`.
